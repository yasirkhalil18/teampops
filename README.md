# FROSTBOUND: The Long Descent

> **3D Open World Winter Survival Game** built with Three.js, WebGL & Vite.

---

## 🎮 Play & Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or newer recommended)

### Quick Start
```bash
# 1. Clone repository
git clone https://github.com/yasirkhalil18/teampops.git

# 2. Enter folder
cd teampops

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open your browser and navigate to `http://localhost:5173/` to play!

---

## ✨ Key Features
- **Exploration & Progression:** 6 Atmospheric Chapters from Solstice Village across gorges, rivers, and icy crags to the Summit Radio Tower.
- **Dynamic Weather & Time:** Realistic day-night cycles, golden dawn/sunset alpenglow, blizzards, and cold temperature simulation.
- **Wildlife & Ecosystem:** Living deer herds, galloping wild horses, flocking birds, rabbits, wolves, and swimming river fish.
- **Crafting & Survival:** Gather pine wood, craft campfires, manage warmth and torches, scavenge supplies, and restore power.
- **Cinematic Trailer & HD Screen Recording:** 3-minute camera tour with voiceover narration and built-in full HD MP4 video recorder.

## 🛠️ Controls
- **W, A, S, D:** Walk & Strafe
- **Shift:** Sprint
- **Space:** Jump
- **Mouse:** Look around (Click canvas for pointer lock)
- **Left Click:** Swing stick / attack
- **E:** Interact / Talk / Pick up
- **F:** Toggle Torch
- **C:** Craft Campfire (Requires Wood)
- **Tab:** Open Backpack & Inventory
- **M:** Map & Navigation Compass
- **V:** Toggle First Person / Third Person Camera
- **P:** Toggle Cinematic Post-Processing
- **G:** Fullscreen Mode
- **U:** Unstuck / Teleport to safe path
- **Esc:** Pause / Release mouse lock
